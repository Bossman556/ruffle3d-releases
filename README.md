# Ruffle3D downloads

Installers for [Ruffle3D](https://www.ruffle3d.site), parametric CAD for product design.

Download from **[ruffle3d.site/download](https://www.ruffle3d.site/download.html)**, or pick a version under
[Releases](../../releases). Each release lists the SHA-256 of its files.

This repository only hosts the installer files. Ruffle3D is commercial software: using it is covered by the
[licence agreement](https://www.ruffle3d.site/legal/eula.html), and paid plans are unlocked with a licence key
from [the store](https://www.ruffle3d.site/pricing.html).
